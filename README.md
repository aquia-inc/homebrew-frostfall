# Frostfall Homebrew Tap

Homebrew tap for [Frostfall](https://github.com/aquia-inc/frostfall),
accessibility testing for rendered web apps.

## Install

```bash
brew tap aquia-inc/frostfall
brew install frostfall
```

Upgrade with `brew upgrade frostfall`.

## About this repository

The formula in this repository is generated and pushed automatically by
Frostfall's release pipeline on every release. Do not edit it by hand and do
not open pull requests here - changes would be overwritten by the next
release.

- Bugs and feature requests: [aquia-inc/frostfall/issues](https://github.com/aquia-inc/frostfall/issues)
- Security reports: [frostfall security policy](https://github.com/aquia-inc/frostfall/security/policy)
